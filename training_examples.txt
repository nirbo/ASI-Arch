# Available LR schedulers: linear, cosine, cosine_with_restarts, polynomial,
#                          constant, constant_with_warmup, inverse_sqrt, reduce_lr_on_plateau

# Sophia optimizer notes:
# - Second-order optimization often converges faster than AdamW/Lion
# - Uses more memory (~10-20% increase) for Hessian approximation
# - Recommended learning rates: 5e-5 to 1e-4 (lower than first-order optimizers)
# - Works well with cosine learning rate schedules
# - Sophia-G uses Gauss-Newton approximation, Sophia-H uses Hutchinson's method
